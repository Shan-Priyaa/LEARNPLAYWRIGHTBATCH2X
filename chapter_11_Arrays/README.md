---

## 💡 Pro Tips

- Arrays in JavaScript are **zero-indexed** — the first element is at index `0`
- Arrays can hold **mixed data types**: numbers, strings, booleans, objects, even other arrays!
- Use `const` to declare arrays — the reference stays the same, but contents can change
