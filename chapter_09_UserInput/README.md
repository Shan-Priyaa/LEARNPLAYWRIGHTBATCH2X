![Node.js](https://img.shields.io/badge/Node.js-18+-339933?logo=node.js&logoColor=white)

Learn how to accept **user input** in Node.js using `prompt`, `readline`, and `prompt-sync`.

---

## 🗂️ Files Overview

| File | Description |
|------|-------------|
| `68_User_Input.js` | Basic user input using `prompt` (browser-style) |
| `69_Node_readline.js` | Input with Node.js built-in `readline` module |
| `70_prompt_sync.js` | Synchronous input using `prompt-sync` package |

---

## 🚀 How to Run

```bash
node 69_Node_readline.js
node 70_prompt_sync.js
```

> 💡 **Note:** `68_User_Input.js` uses `prompt()` which is intended for browser environments.

---

## 🎯 Learning Outcomes

- ✅ Accept user input in Node.js scripts
- ✅ Use `readline` for async input
- ✅ Use `prompt-sync` for synchronous input
