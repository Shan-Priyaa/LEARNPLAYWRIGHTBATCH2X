## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Shan-Priyaa/LEARNPLAYWRIGHTBATCH2X.git
```

### 2. Open in VS Code
```bash
cd LEARNPLAYWRIGHTBATCH2X
code .
```

### 3. Run your first JS file
```bash
node chapter_01_Basics/01_Basics.js
```
