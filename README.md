## 📁 Folder Structure

| Chapter | Folder | Description |
|---------|--------|-------------|
| 01 | [`chapter_01_Basics/`](chapter_01_Basics/) | Basics of JavaScript and setup verification |
| 02 | [`chapter_02_Javascript_Concepts/`](chapter_02_Javascript_Concepts/) | JavaScript basics: variable declarations using `var` |
| 03 | [`chapter_03_Identifier_Literals/`](chapter_03_Identifier_Literals/) | Identifier rules, literals, VS Code shortcuts, and comments |
| 04 | [`chapter_04_Javascript_Concepts/`](chapter_04_Javascript_Concepts/) | JavaScript concepts: `var`/`let`/`const`, functions, scope, hoisting |
| 05 | [`chapter_05_Literal/`](chapter_05_Literal/) | Literals, `null` vs `undefined`, strings, numbers, and backtick usage |
| 06 | [`chapter_06_Operator/`](chapter_06_Operator/) | Operators: arithmetic, modulus, exponent, comparison, logical, string concatenation |
| 07 | [`chapter_07_If_else/`](chapter_07_If_else/) | Conditional statements: `if`, `else if`, `else`, real-world & IQ problems |
| 08 | [`chapter_08_Switch_Statement/`](chapter_08_Switch_Statement/) | `switch` statement, fall-through, grouping, API validation |
| 09 | [`chapter_09_UserInput/`](chapter_09_UserInput/) | Accepting user input: `prompt`, `readline`, `prompt-sync` |
| 10 | [`chapter_10_Loops/`](chapter_10_Loops/) | Loops: `for`, `while`, `do...while`, `for...of`, `for...in`, and IQ questions |

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Shan-Priyaa/LEARNPLAYWRIGHTBATCH2X.git
   ```
2. **Open the folder in VS Code:**
   ```bash
   cd LEARNPLAYWRIGHTBATCH2X
   code .
   ```
3. **Run JavaScript files using Node.js:**
   ```bash
   node chapter_01_Basics/01_Basics.js
   ```
